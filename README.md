### ✅ **Overview**

**hello\_stores** is a Flutter-based multi-tab application designed to display project and unit information for real estate buyers. It fetches applicant details, agreement info, and allotment summaries from Firebase using GetX for state management. The UI is responsive, clean, and organized with cards and tab views, ensuring a smooth experience on all screen sizes.

# hello_stores

A responsive, multi-tab Flutter application for showcasing real estate unit details and buyer information. The app integrates with Firebase and uses GetX for state management to display key sections like Applicant Details, Agreement Info, and Allotment Summary.

## ✨ Features

- 🧑‍💼 Applicant Details: Image, name, DOB, marital status, PAN, Aadhaar, and contact information shown in styled cards.
- 📜 Agreement & Allotment Tabs: Segmented tab views for organized unit-related data.
- 📦 Firebase Integration: Fetch and display unit and buyer data directly from Firestore.
- 🧠 GetX for State Management: Efficient reactivity and controller-driven logic.
- 📱 Responsive UI: Adapts across mobile screen sizes with consistent layout and spacing.
